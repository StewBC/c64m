## Goal

When Inspect is active, Inspector **replaces** the live `c64_t` with reconstructed
past at the landed cycle. Existing views keep reading the machine.

Leave Inspect -> restore **live NOW** anchor. The machine must not be left in a
random past.

This phase also lands **C64M/8** so socket peers can see Inspect and leave it.
No Misc tab yet (I3); a debug hook / ctest is enough to smoke enter/leave/land.

## Mode model

| Mode | Machine contents | Mutations |
|------|------------------|-----------|
| **Live** | NOW | read-write (existing rules) |
| **Inspect** | Landed THEN | **pokes reject**; sealed execute-forward allowed, clamped to live |

**One true state (D2/D9):** `get-cpu` / `get-memory` / VIC/CIA/SID / published
frame reflect whatever is in `c64_t` now — past while Inspecting.

### Enter Inspect (A7)

1. Pause if running (instruction boundary). Do not auto-resume later.
2. `can_enter`: Inspector on; machine ready; **>= 1 checkpoint**. Film optional.
   HST1 is **not** a gate. Inspector off -> `UNAVAILABLE`. No checkpoints / budget 0
   -> `EMPTY`.
3. `runtime_inspector_checkpoint_take` at live NOW.
4. Save NOW blob (`c64_snapshot_save`; do not flush media).
5. `runtime_inspector_recorder_set_enabled(false)` — detaches input/media
   callbacks so remount/replay cannot cut the tape. **Do not** `history_stop`.
6. **Stay at live.** Do not land the last cadence checkpoint. Machine is already NOW.
7. Stay sealed: observer NULL, mem callback NULL, audio muted.
8. Publish CPU + machine + live frame slot. `state-changed reason=inspector-enter`.

Failed enter restores the NOW blob (if saved), re-enables the recorder, reattaches
observer/mem, clears the seal, does not set Inspect.

Re-enter while already Inspecting is OK (no-op).

### Land (A4, A10)

New worker command, **not** an HST1 walk:

```text
runtime_client_inspector_land(client, cycle, token)
-> if cycle >= live: restore NOW blob (already at live is a no-op publish)
-> else: load nearest checkpoint <= cycle into live c64_t
-> paint (see Display)
-> publish CPU / machine / frame
-> state-changed reason=inspector-land
```

Use I1 `runtime_inspector_load_nearest_checkpoint`. Target **is** the checkpoint
cycle, except the right end which **is** live. Do **not** re-execute toward a
film still. Do **not** walk HST1.

Land outside the timeline -> error; machine unchanged; never half-apply.

A failed land restores the THEN blob taken before the attempt, stays in Inspect,
seal stays on.

### Sealed execute (A6, A9, A13, A14)

Carve out sealed execute, clamped to live. Still reject pokes, reset, media,
assemble, Inspector enable, paste, keys, joystick, load/save-state, etc.

| Key | Live (unchanged) | Inspect after I2 |
|-----|------------------|------------------|
| F10 | pause if running, else step insn | sealed step insn; **no-op at live** |
| F11 | step over | sealed step over; **no-op at live** |
| Shift+F10 | step out | sealed step out; **no-op at live** |
| F12 | run | sealed run until a **breakpoint** or **live**; stay in Inspect |
| Shift+F12 | run to cursor | sealed run-to-cursor; stop at a breakpoint or live |
| Opt+Left | poke PC | **unbound** (I3 keys; worker must still reject `set-pc`) |
| Opt+B | toggle execute BP | **same one list** |

Wire time-travel F10/F12 to the **live** client step/run APIs, with the worker
clamping so execute cannot pass live. I3 connects the keys; I2 must already
accept those commands while Inspecting.

Keep the seal (D16): observer off, no HST1 append, no `runtime_inspector_after_step`
checkpoints (recorder already disarmed on enter), no frame-ring push. Input log
still applies on a long F12 (I1). **D16 is during execute.** On stop, present the
CRT (A16) — helper can land here even if I3 owns the pretty path.

**Breakpoints:** `rt->breakpoints[]` only. Inspect F12 stops on that list or live.
Leave Inspect keeps whatever you added or cleared (debugger state, not inside the
snapshot).

### Frame-step (A5)

```text
runtime_client_inspector_frame_step(client, dir, token)  // dir +1 / -1
```

- **`[+]`:** sealed `c64_step_cycle` until `c64_consume_frame_complete` (one guest
  frame), publish. Disable at live. If the next frame would pass live, stop at live.
- **`[-]`:** land earlier CP, sealed re-execute to "one frame before current cycle"
  (use VIC `frame_complete`, not a magic PAL constant). Disable if that target is
  before the oldest checkpoint.

Do not HST1-walk.

### Leave Inspect (A8) — infallible

1. `c64_snapshot_load` of the NOW blob into `c64_t`.
2. Unseal; reattach mem callback + CPU observer; re-enable recorder if Inspector
   is still on (takes a CP at restored NOW).
3. Mode=live; free the NOW blob.
4. Publish + `state-changed reason=inspector-leave`.
5. **Do not** auto-resume.

The NOW blob is independent of the tape. Wiping checkpoints mid-session then
leaving still restores CPU, RAM, 1541, and SID. Exit with no Inspect session is
a no-op that still publishes leave.

## Display under the head — pinned

`c64_snapshot_load` does **not** restore paint buffers (`machine.md`). After land
on a checkpoint (replay span 0):

1. Publish a CRT of the landed machine. c64m has no Apple `paint_full_frame`.
   Implement a current-state VIC picture from registers+RAM for this path
   (mid-frame splits can be wrong vs a recorded still — accepted, same as a2m).
2. Frame-step `[+]` then beam-paints a real guest frame.

While dragging (I3), the CRT is **film or pink**, not this paint.

**Stop path (A16)** — one helper, used in live and Inspect:

| Condition | Present |
|-----------|---------|
| Paint off (warp, sealed F12 run) | Dump from current VIC+RAM, then publish. There is no beam image. |
| Otherwise | Publish the **beam buffer**. Do not dump. A mid-scanline mode switch must still show. |

c64m has no Hardware Override page; do not invent one. D16 still holds *during*
sealed F12 (paint off, no ring push). The helper runs **on stop**. Gate:
`runtime_display_stop` / `runtime_publish_presented_frame` (pick names; keep one).

## Read-only enforcement

Runtime must reject while Inspecting, **before** cursor-invalidate / state-changed,
with `RUNTIME_EVENT_ERROR` `code=read-only-inspector`:

reset, mem/reg poke, `set-pc`, save/load-state, load-bin, assemble, media
insert/eject/swap, machine-config apply, paste, key, joystick, history-clear/record,
`INSPECTOR_SET_ENABLED`.

Allowed: get-*, BP edits, turbo, enter/leave/land/frame-step, and the sealed
step/run family (clamped to live).

Control dispatch mirrors the mutation set and returns `error read-only-inspector`
immediately so `set-memory` / `set-reg` / `run` (the unclamped live run) never
post `ok`. Sealed F12 is an Inspect-mode run, not the live `run` verb — pin the
split in Landed. Socket `run` while Inspecting should mean sealed-to-breakpoint-or-live
**or** reject; **pin: reject live `run` / `step-*` from the socket unless they go
through the Inspect execute path.** Simplest: socket `step-*` / `run` while
Inspecting perform sealed execute (same as UI). Document it.

## Control surface (D18) — C64M/8

Inspect is a **global** state: while a UI user is landed, every socket peer's
`get-memory` returns past bytes and mutating verbs fail. Shipping that
client-only would leave agents silently misled.

| Need | Surface |
|------|---------|
| "Am I looking at the past?" | `get-state` gains `mode=live\|inspector` + `focus_cycle=` + `start=` + `start_arg1=` |
| "Get me out" | `leave-inspector` — any session; `ok accepted=1` (fire-and-forget like pause) |
| "Something moved" | `state-changed` reasons `inspector-enter` / `inspector-land` / `inspector-leave` |
| "Why did my poke fail?" | `error read-only-inspector` |

Also:

- `hello` / `version`: `protocol=C64M/8`
- `capabilities` adds `inspector`
- Land / frame-step are **not** required wire verbs (UI uses `runtime_client`).
  `leave-inspector` is required. `enter-inspector` is optional fire-and-forget.
- `focus_cycle` = landed `c64` cycle, not an HST1 id
- `start` is the D10 left-edge reason (`unknown` / `guest-write`); `start_arg1` is device where known
- Teach `tools/c64_control_client.py`
- Update [`control-port.md`](control-port.md) and [`using-c64m.md`](using-c64m.md) in the same change

Bind still lives in `src/main.c`.

## Landed

2026-08-23. Inspect mode replaces the live `c64_t` with reconstructed past.
I1 scratch `materialize` is unchanged. Recording stays opt-in and does not arm
HST1.

**Enter:** pause at an instruction boundary; `can_enter` is checkpoints-only
(HST1/film are not gates); take a CP at NOW; save the NOW blob; disarm the
Inspector recorder (not HST1); stay at live; seal observers/mem/audio. Re-enter
is a no-op.

**Leave:** restore the NOW blob (infallible even if CPs were wiped); unseal;
reattach live hooks; re-enable the recorder if Inspector is still on. Does not
auto-resume. Leave with no session still publishes `inspector-leave`.

**Land:** `cycle >= live` restores NOW; else load nearest CP `<= cycle` into
`rt->machine` (no HST1 walk, no re-execute toward a still). Outside the
timeline errors and leaves the machine unchanged. A failed land restores the
THEN blob taken before the attempt.

**Sealed execute:** worker `run` / `step-*` / `step-over` / `step-out` /
`run-to-cursor` while Inspecting are clamped to live. No-op at live. F12 stops
at a breakpoint or live and stays in Inspect. Input log still applies.
Recorder already disarmed, so no new CPs / HST1 rows / frame-ring pushes.

**Display stop helper:** `runtime_publish_presented_frame` (A16). Paint off
(warp, sealed F12) dumps VIC+RAM; otherwise publishes the beam (`c64_copy_paint_frame`).
Checkpoint land with empty paint buffers dumps via `c64_make_current_frame_snapshot`.

**Read-only:** worker rejects pokes before cursor-invalidate with
`RUNTIME_EVENT_ERROR` `code=read-only-inspector`. Control dispatch rejects the
same mutation set immediately. Socket `run` / `step-*` are the Inspect execute
path, not the unclamped live line.

**C64M/8:** `hello`/`version` `protocol=C64M/8`; capability `inspector`;
`get-state` `mode=live|inspector focus_cycle= start= start_arg1=`;
`leave-inspector` (required) and optional `enter-inspector`; `state-changed`
reasons `inspector-enter` / `inspector-land` / `inspector-leave`.

Tests: `test_runtime_inspector_mode`, `test_control_protocol` leave/enter parse,
`inspector_control_integration`.
