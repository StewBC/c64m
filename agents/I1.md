## Goal

Record a retained window of **checkpoints + inputs** so tests (and I2) can answer
"machine state at cycle C" by **re-executing** from the nearest checkpoint under a seal.

This phase records and can materialize into a **scratch** `c64_t`. Wiring that onto
the live product machine as Inspect mode is **I2**.

---

## Non-goals

- Replacing live machine during Inspect (I2)
- Misc UI (I3)
- Max/warp Record wipe (I4) — I1 records at turbo 1 **and** max/warp; I4 changes that
- Rewinding host file content, or scrubbing across a media write (D10)
- Audible Inspect audio (D11)
- Changing HST1 format
- A write-delta stream (D5a)
- Promote / Branch
- HST1 tape-nav
- `c64_snapshot` version bump unless a guest-visible PRNG actually appears (none in `src/` today)

## Storage model

```text
When Inspector recording ON:

  [CP0] --inputs--> [CP1] --inputs--> ... --inputs--> live head
         ^                                  cadence: one guest frame of cycles
         frame ring continues as today (join key: machine_cycle)
         HST1 may also be on; Inspector does not own it

  materialize(C) = load nearest CP <= C, then re-execute SEALED to C
```

| Layer | Role |
|-------|------|
| **Checkpoint** | Coherent full machine slice at cycle C_k — `c64_snapshot_save` blob |
| **Input log** | Timestamped host key / joystick between checkpoints |
| **Frame ring** | Film preview (unchanged role) |
| **HST1** | Forensic FIND (unchanged; not in the Inspector timeline) |

### Checkpoint = `c64_snapshot_save`

**Pin: reuse the existing serializer.** `c64_snapshot_save` / `load` / `size` in
`src/machine/c64_snapshot.{c,h}`. Format version 13. Covers CPU, RAM/color RAM,
banking, VIC-II **chip** state (not paint buffers), CIA, SID, cart, and powered
1541 drive objects (CPU including mid-micro, VIAs, RAM, GCR tracks).

- **Do not** hand-roll a second layout for V1.
- **Never** flush host D64/G64 on this path. Cadence would hit the filesystem
  tens of times per second.
- `c64_snapshot_size` returns 0 mid-main-CPU-micro; take checkpoints on an
  instruction boundary (the runtime already finishes the pending instruction
  before save-state).
- Paint buffers are zeroed on load. I2/I3 own display policy.

**Measure in Landed:** blob bytes with no disk, with one 1541 D64, with G64.
128 MiB / that size is the slot count. Do not invent ~800.

### Input / nondeterminism log

Everything re-execution cannot derive from the checkpoint, timestamped by
`machine.clock.cycle`:

| Source | Handling |
|--------|----------|
| Keyboard | Log `c64_set_key` + cycle |
| Joystick | Log `c64_set_joystick` + cycle |
| Paste | Covered because it goes through `c64_set_key` |
| `rand()` | **None in `src/` today.** If a guest-visible one appears, seed a machine-local PRNG into the snapshot in the same change and bump `C64_SNAPSHOT_VERSION` per `machine.md` (MIN moves with VERSION). |

Versioned append-only ring. Apply on replay between CP cycle and target.

### Cadence (initial pin — tune from metrics)

- **Cycle-capped**, not frame-capped: checkpoint every
  `c64_config_cycles_per_frame` Phi2 cycles (PAL **19656**, NTSC **17095**) so
  worst-case replay is about one frame.
- Forced checkpoint on recorder start and on Inspect enter (I2).
- Drop oldest checkpoint (and its input-log span) when over budget; keep honesty
  counters (dropped, oldest cycle retained).

Do **not** implement the discarded a2m "stop on max, truncate to RECORDER_RESUME
on leave" behaviour. I4 is the max/warp product.

## Sealed replay (D16) — the correctness core

Re-execution runs real code, so every side-effect path must be muted for the duration.
**A leaky seal corrupts the tape you are standing on.**

| Gate | Mechanism |
|------|-----------|
| CPU observer | `c64_set_cpu_observer(m, NULL, NULL)` — else replay appends HST1 rows (`runtime_thread.c`) |
| Memory-access callback | Detach `c64_set_memory_access_callback` — it is installed permanently and would fire watchpoints/BPs |
| Frame ring / publish | No `runtime_frame_ring_push`, no live-slot publish until the head lands / stop |
| Audio | Do not emit into `audio_out`; `c64_set_audio_output_enabled(m, false)` on the replay machine |
| Media write-through | **Safety net.** Window never spans a guest write (D10), so replay cannot re-execute one. Keep a machine-level replay flag that drops 1541 host image writes (GCR + job-buffer + KERNAL SAVE trap persist) anyway |

Implement the seal as one scoped enter/exit pair, not five scattered flags, and
assert on exit that live recorder counters are unchanged.

Scratch `dst` has no live observer/watchpoint/audio path — those gates are
structural here. Dedicated live-machine tests are I2.

## Media writes cut the window (D10)

**The rule: a guest media write that succeeds truncates the Inspector window at
that cycle.** A write the drive refuses changes nothing. Checkpoints, inputs, and
film older than the write are dropped; recording continues forward. You can never
Inspect back across a disk write.

**Why, in one line:** media bytes live outside the checkpoint, so a replayed read
returns *present-day* bytes.

### What counts as a guest media write

| Truncates | Anchor |
|-----------|--------|
| 1541 GCR bit write | `set_track_bit` / `tr->dirty = 1` in `c1541_media.c` after the writable sense has allowed writing |
| 1541 job-level sector write / format | `c1541_copy_job_buffer_to_sector` / `c1541_format_track` after `slot->writable` (those set `slot->dirty`) |
| KERNAL SAVE trap | `c64_try_kernal_save_trap` on **success** (host image mutated when 1541 emulation is off) |

Writable-off returns `C1541_JOB_WRITE_PROT` / sense before dirty — **must not cut**.

| **Must not truncate** | Why |
|---|---|
| `c1541_media_sync_dirty_to_d64` / `_g64` | housekeeping export to the host file |
| `runtime_save_state` | save-path; does not currently sync dirty as a guest write |
| Eject / unmount flush | housekeeping |
| Writes dropped during sealed replay | by construction there are none; if one appears, that is a bug, not a truncation trigger |

Mount / reset / load-state already invalidate history; they must also wipe or
epoch-cut Inspector checkpoints (same class as sessions mutation set). That is
an invalidate, not a D10 media-cut.

### Shape

- **Truncate old, do not clear all.** Advance window oldest to the write cycle;
  keep recording forward.
- Append **one** new `runtime_history_marker_kind` —
  `RUNTIME_HISTORY_MARKER_MEDIA_CHANGED` (next free value, **13**) — with the
  cause in `marker_arg0`. One kind, sub-kind enum:

  ```c
  typedef enum runtime_history_media_change_kind {
      RUNTIME_HISTORY_MEDIA_CHANGE_UNKNOWN = 0,
      RUNTIME_HISTORY_MEDIA_CHANGE_GUEST_WRITE = 1
  } runtime_history_media_change_kind;
  ```

  (a2m also has `HOST_DIRECTORY` for HostFS; c64m has no HostFS — do not add it.)
  Put device number in `marker_arg1` where known so the UI can say
  `disk write, device 8 @ cycle N`.
- **Order: append the marker, then truncate _to_ it, not past it.** The marker
  must survive as the new oldest HST1 record if HST1 is recording; Inspector
  drops CPs/inputs/frames older than that cycle regardless.
- Marker 13 is additive on HST1 FIND/READ (`marker_kind` u16). Document it in
  [`control-port.md`](control-port.md). Expected: **no C64M bump** (I2 owns C64M/8).
- Honesty counter of truncations.

## APIs (worker-internal + testable)

Illustrative names (use these):

```text
runtime_inspector_recorder_set_enabled(rt, bool)   // gated by I0 master
runtime_inspector_checkpoint_take(rt)              // force CP at current cycle
runtime_inspector_materialize(rt, cycle, c64_t *dst)  // load CP<=cycle + sealed re-exec; dst is scratch
runtime_inspector_load_nearest_checkpoint(rt, cycle)  // load only; used by I2 land
runtime_inspector_window_info(rt, ...)             // oldest/newest checkpoint cycle, counts, dropped, start kind
runtime_inspector_after_step(rt)                   // cadence; no-op when recorder off
runtime_inspector_on_media_event(...)
runtime_inspector_on_history_invalidate(rt)        // reset / load-state / clear
```

- `materialize` in I1 targets a **scratch** `c64_t`; it must not disturb the live machine.
- When recording **off**: zero cost on the insn path.
- Timeline for this product is checkpoint coverage, **not** HST1 ∩ frames ∩ CPs.
  A zero film budget does not empty the Inspector tape (A7). A zero
  `inspector_memory_mb` does.

Extend I0 `runtime_inspector_set_enabled` off->on with
`runtime_inspector_recorder_set_enabled(true)`.

## Opt-in gating

- I0 master off -> no checkpoint/input-log work.
- Clear on history clear / state load / reset / media replace of the same class
  that already invalidates rings. Checkpoints must not be replayable across an
  epoch boundary.

## Testing

| Test | Expect |
|------|--------|
| CP round-trip | take CP -> load into scratch -> CPU/mem/flags/VIC/CIA/SID/1541 match |
| Mid-window | run N insns with recording -> materialize at mid cycle -> match golden |
| **Determinism** | materialize same cycle twice -> byte-identical |
| **Seal: observer** | HST1 record count unchanged across a materialize |
| **Seal: watchpoints** | armed watchpoint does not fire during materialize |
| **Seal: frame ring** | frame ring count/contents unchanged |
| **Seal: media** | mtime + bytes of a mounted D64/G64 unchanged across a materialize |
| **Media truncate** | guest disk write -> window oldest on the `MEDIA_CHANGED` marker; forward recording continues |
| **Housekeeping does not** | eject / save-state / `sync_dirty` leave the window intact |
| **Refused write does not** | writable-off: guest write attempt -> window unchanged, no marker |
| Budget drop | fill past budget -> oldest advances; window honest |
| Off path | enable off -> insn path does not grow Inspector buffers |

Prefer deterministic headless runtime tests (`tests/runtime/test_runtime_history_*.c` pattern).

## Landed

2026-08-23. Checkpoint ring + input log + sealed materialize to scratch. No
Inspect-replace-live (I2). Snapshot version **unchanged** (still 13).

**Cadence:** `c64_config_cycles_per_frame` Phi2 cycles (PAL 19656, NTSC 17095).
Forced checkpoint on recorder start and after reset/load-state/history-clear
invalidate.

**Measured blob (no disk, no cart, NTSC test machine):** 67652 bytes.
128 MiB / 67652 = **1983** slots. Do not use an ~800-slot story. Powered 1541
with GCR in `DR8C`/`DR9C` is much larger; slot count is `128 MiB / blob` for
that machine. Typed `inspector_memory_mb=0` still allocates nothing.

**Seal:** `c64_set_replay_sealed` plus observer/mem-callback/audio off on the
scratch `dst`. Live HST1 and frame-ring counts are asserted unchanged across
`materialize`. Guest 1541/KERNAL writes are dropped while sealed.

**D10:** successful guest writes append HST1 marker 13
(`RUNTIME_HISTORY_MARKER_MEDIA_CHANGED`, arg0=`GUEST_WRITE`, arg1=device),
then truncate Inspector CPs/inputs/film older than that cycle. Housekeeping
(`save-state`, `c1541_media_sync_dirty`) does not cut. Write-protect returns
before dirty and does not notify.

**API:** `runtime_inspector_load_nearest_checkpoint(rt, cycle, dst)` takes a
destination so I1 can load a scratch machine; I2 passes `&rt->machine`.

Tests: `test_runtime_inspector_replay`; job-level notify in `test_c1541`.
