## Goal

One debugger interface: **live** and **Inspect** share F9 chrome. Inspector is a
**Misc tab + mode**, not a second application.

**Win:** slam the thumb left — UI stays live, CRT shows film or pink, C64 does not
move. Release **lands** (snapshot load, ~ms). `[-]`/`[+]` frame-step that C64.
F10-family **re-executes** toward **live**. HST1 is not on this path.

---

## Non-goals

- Dropping the frame ring (A11)
- Locking checkpoints to VBL
- Reverse CPU
- Using HST1 for scrub, land, or Inspect F10
- Dual coarseness sliders
- Promote / Branch
- Max/warp wipe policy (I4); I3 must still show honest Record state
- Flaky automated UI tests
- Binding host F7 to Inspector (C64 F7 is a guest key; F9 remains the debugger)
- A second breakpoint bank or Breakpoints-tab extras

## UX

```text
Pause -> Inspect (enter time travel at live). Leave still restores NOW, paused.

  [-]  [======== thumb ========]  [+]

Thumb  = current cycle on oldest snapshot -> live (right = live).
         Drag is preview only; C64 frozen.
         After land / +/- / F10-family, thumb follows cycles.

Thumb down  -> CRT = stored film OR pink. C64 frozen.
Release     -> land (checkpoint <= time, or live at the right end).
               CRT = paint of the landed C64 (never leave the user on pink).
Grab again  -> preview again; C64 frozen until the next land.

After land (still in Inspect):
  [-] / [+]          one guest video frame (disabled at oldest / live)
  F10 / F11 / Shift+F10
                     insn step / over / out  (no-op at live); CRT on stop (A16)
  F12                re-execute to a breakpoint or live; stay in Inspect; CRT on stop
  Shift+F12          run-to-cursor; stop at a breakpoint or live; CRT on stop
  Opt+Left           unbound
  pokes              reject (read-only)
```

Scrubber copy should say the bar is **retained snapshots -> live**, stills where
we have them, pink where we do not.

### Misc -> Inspector tab (A18)

Today the misc tabs are Machine / Debugger / Breakpoints / Hardware / Assembler
(`FRONTEND_MISC_TAB_*` in `src/frontend/frontend.c`). Add **Inspector** as a
sixth tab. Prefer two rows of three if six-across is tight — pin the layout in
Landed.

| State | Tab shows |
|-------|-----------|
| Record off | `[ ] Record` only |
| Record on, not Inspecting | **Inspect** (worker pauses if running) plus History start cycle / Live cycle / Duration |
| Inspecting | **Leave Inspector**. Then `[-]` slider `[+]`. Then Current cycle and the same three lines. No Record row, no help dump |
| Empty window | Honest: Record off, budget 0, or nothing recorded |
| Window cut by D10 | Left-edge reason: `disk write, device N @ cycle X` |

No Pause on this tab. Duration is guest seconds:
`(live - oldest) / c64_config_clock_hz`.

Recording toggle is `runtime_client_inspector_set_enabled` (I0). Locked while
Inspecting (I2 rejects `INSPECTOR_SET_ENABLED`).

### Whole debugger in Inspect

- Visual cue: cobalt **headers only** (A17). Do not tint the window background.
- All value setters read-only (reject); rely on I2 runtime reject too.
- Display / mem / VIC / CIA / SID / regs: normal views on one true state.
- Breakpoints tab is the **live** panel in both modes (A14). No Inspect-only copy,
  no "Run to breakpoint" button. Inspect **F12** is the run-until.

### Keys

Reuse I2 worker behaviour. `src/main.c` already maps F10/F11/F12 and Opt+Left /
Opt+B. While Inspecting:

- F10-family / F12 hit live client step/run (I2 clamps).
- Opt+Left: **do not dispatch** `set-pc`.
- Opt+B: existing BP list.

**Pinned: host F7 stays unbound for Inspector.** Do not rebind it as "go to
Inspector." The Misc tab is the entry (D15).

## Implementation notes

### Order of work

1. Tab chrome (A18) calling I2 enter/leave; Record checkbox.
2. Slider: oldest snapshot -> live; **thumb down never lands**; thumb up one
   `inspector_land`. Preview = `runtime_frame_ring_copy_by_cycle` or pink.
3. `[-]`/`[+]` -> `inspector_frame_step`. Disabled at oldest / live / during drag.
4. Keys as above. Cobalt headers (A17).
5. Manual.md + help regen. Manual smoke.

### Slider details

- Domain = cycle-linear oldest checkpoint -> live (NOW blob). Thumb = current
  `clock.cycle` when not dragging.
- Stop: do not send a land/seek on every tick.
- Grab hit-test: `nk_widget_bounds` **before** `nk_slider_int`. After the slider,
  peek is the `[+]` slot — using that makes `[+]` look like a rewind.
- Preview must not wait on materialize. Prefer a UI-thread blit if
  `runtime_client` can lock the frame ring. Else a coalesced preview that only
  copies pixels or paints magenta — never an HST1 walk.
- Film is indexed8. Blit through the existing presentation path (Pepto expansion
  at the CRT). Pink is host RGB `(255,0,255)` in the CRT **client rect**, not a
  C64 colour index.

### What must not happen

- Inspector drag/land/`±`/F10 -> HST1 `previous()` / any tape-nav
- Enter Inspect failing because HST1 or frame ring is off
- Enter jumping to the last cadence checkpoint instead of staying at live
- Time-travel F10 calling a removed TM1-style client
- Time-travel Opt+Left poking PC
- Execute past live, or F12 exiting Inspect / resuming the live line
- New checkpoints or HST1 rows while in Inspect (seal + recorder off)
- Auto-resume on leave

## Landed

2026-08-23. One debugger skin: live and Inspect share F9. Inspector is the sixth
Misc tab. Host F7 stays unbound. HST1 is not on this path. I4 max/warp wipe is
not claimed.

### Tab chrome (A18)

Two rows of three: Machine / Debugger / Breakpoints, then Hardware / Assembler /
Inspector.

| State | Tab |
|-------|-----|
| Record off | `[ ] Record` only |
| Record on, not Inspecting | **Inspect** (I2 enter pauses if running) plus History start cycle / Live cycle / Duration |
| Inspecting | **Leave Inspector**. Then `[-]` slider `[+]`. Then Current cycle and the same three lines. No Record row |
| Empty window | `No Inspector snapshots yet.` |
| Window cut by D10 | `disk write, device N @ cycle X` |

Duration is `(live - oldest) / inspector_clock_hz` (PAL 985248 / NTSC 1022727 from
the machine). Recording toggle is `runtime_client_inspector_set_enabled`. Locked
while Inspecting (row hidden; I2 still rejects `INSPECTOR_SET_ENABLED`).

### Slider (A1-A5, A12)

Domain = oldest checkpoint -> **live** (`runtime_inspector_timeline_bounds`),
0..1000. Thumb = focus cycle when not dragging. Grab uses `nk_widget_bounds`
**before** `nk_slider_int`. Drag never posts land; pending LAND intents are
coalesced. Release posts one `inspector_land`. `[-]`/`[+]` ->
`inspector_frame_step`; disabled at oldest / live / while the thumb is down.

### Film / pink (A3)

Thumb down: UI-thread `runtime_client_copy_frame_at(..., by_cycle)` then
`frontend_submit_frame` (indexed8 through Pepto). Miss -> CRT **client rect**
fill host RGB `(255,0,255)`, not a C64 index. Release lands and I2 paints the
C64 (never left on pink).

### Keys / chrome

F10-family / F12 hit the live client step/run APIs (I2 clamps). Opt+Left is
unbound in Inspect. Opt+B is the live BP list. Pokes, paste, keys, joystick,
quicksave/load, assemble, and Configure apply are dropped in the UI; worker
reject remains. Headers `nk_rgb(24, 62, 118)` / hover `32, 76, 136` / active
`40, 88, 152`; no background tint. Title `c64m - VIDEO - TURBO - Inspect`.

GUI smoke is the playbook in this file. Stop. Do not start I4.
